# SWYNEX-Exploratory-Data-Analysis
# SWYNEX Internship Task 2: Exploratory Data Analysis

## Overview

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies.

The objective of this task was to perform Exploratory Data Analysis (EDA) on a cleaned FMCG retail transaction dataset and identify important statistics, trends, patterns, and anomalies.

## Dataset

The dataset contains FMCG retail transaction records with the following information:

- Transaction ID
- Customer Name
- Email
- Age
- Country
- Product Category
- Unit Price
- Quantity
- Transaction Date
- Payment Method
- Revenue

The cleaned dataset contains **1,480 transaction records**.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Google Colab
- GitHub

## EDA Performed

The analysis included:

- Dataset structure and information
- Descriptive statistics
- Product category analysis
- Country-wise analysis
- Payment method analysis
- Revenue analysis
- Monthly revenue trends
- Monthly transaction trends
- Quantity and revenue analysis
- Unit price and revenue analysis
- Outlier detection using the IQR method
- Data visualizations

## Key Insights

1. Electronics generated the highest total revenue among the product categories, with ₹17,33,594.72.

2. Nigeria recorded the highest total revenue among the countries, with ₹14,75,058.34.

3. Card payments generated the highest total revenue, with ₹22,95,070.96.

4. Average transaction revenue increased as the quantity purchased increased.

5. Higher unit-price transactions generally had higher average revenue.

6. Monthly revenue fluctuated throughout the dataset period, with August 2025 recording ₹2,54,070.12.

7. The IQR method identified 105 high-revenue outlier transactions.

## Conclusion

The exploratory data analysis helped identify important patterns and relationships within the FMCG retail transaction dataset. The analysis provided insights into revenue distribution, product categories, countries, payment methods, transaction quantities, pricing, and monthly trends.
